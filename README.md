# IQD → USDT Calculator

Simple calculator for converting IQD to USDT.

## Install
```bash
sudo bash install.sh
```

## Features
- Real-time calculation
- Quick amount chips (100K, 500K, 1M, 5M)
- Reference table
- Tap to copy result
- Remembers last rate & amount

## Default Rate
1542.99 IQD = 1 USDT
